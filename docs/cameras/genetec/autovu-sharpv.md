## Features

- dedicated License Plate Recognition (ALPR) camera
- fixed ALPR unit with onboard (edge) ALPR processing and machine-learning analytics; no reliance on remote servers for analysis
- dual imagers: 1920x1200 monochrome global-shutter ALPR sensor + 1920x1200 color global-shutter context camera, both 30 fps
- capture range 3-45 m (9-148 ft), per Genetec under ideal conditions
- integrated pulsed LED illuminator for 0 lux (total darkness); 940, 850, 740 and 590 nm wavelength options
- motorized lenses with auto-focus for remote zoom and focus configuration
- onboard analytics: vehicle type, vehicle color, speed estimation, direction of travel, virtual loop, plate origin (state/country, some regions)
- optional built-in 4G/LTE Cat 4 radio with GNSS (GPS, Glonass, Beidou, Galileo, QZSS); LTE models -0M0 (global) and -0M1 (North America)
- video streaming H.264 up to 30 fps, MJPEG up to 15 fps; JPEG ALPR and context stills
- 2 opto-isolated inputs / 2 outputs for induction-loop integration
- IP66/IP67; IK09 with tamper guard kit (IK06 for 4G/LTE option); MIL-STD-810H vibration
- available in security white or black; pole and wall mount included
- integrates with Genetec Security Center
