## Features

- dedicated License Plate Recognition (ALPR) camera
- dual-purpose: multi-lane LPR plus color security video in one camera, with separate monochrome global-shutter LPR imager and color global-shutter context imager
- capture range 20-250 ft, capture speed up to 100 mph
- image resolution 1440x1080 (4:3); datasheet image-performance header also lists 3.0MP
- pulsed LED illumination 850nm (VSM-L6D-8IR) or 730nm (VSM-L6D-7IR)
- analytics: plate, state/region, make, model, color, speed, direction of travel, GPS location
- ONVIF Profile S; H.264 and Motion JPEG
- 8GB RAM, 64GB flash; Secure Boot, FIPS 140-2 Level 3 certified TPM, 802.1X
- 1000BASE-T, WiFi 802.11a/b/g/n/ac; optional 5G Hub (VSM-5GHUB-4)
- IR cut filter, tamper-proof charcoal grey housing
