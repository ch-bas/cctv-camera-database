## Features

- Rugged outdoor 360-degree fisheye camera, 8MP sensor, 4.7MP (2160x2160) max resolution at up to 60 fps
- single 180-degree 1.6mm F2.0 all-glass fixed-focus fixed-iris fisheye lens, automatic/manual day-night IR cut filter (no IR illuminator)
- IP66/IP67/IP68/IP69K, IK10 and NEMA Type 4 & 6 rated; EN 50155 / EN 45545 transport certified
- TrueDetail HDR up to 30 fps, 120 dB dynamic range, Advanced Light Management
- Plus Board: 8-28 VDC support, 2x alarm input / 1x alarm output, 2x LED lamp control, audio input (G.711/AAC) via screw terminals
- Multi-Mode: up to 4 concurrent streams from a choice of 5 views incl. edge dewarping (Fisheye, Panoramic+, Corridor+, T Corridor+, VCam)
- StreamLite / StreamLite+ smart compression (H.264/H.265 with ColorMap), 10x client-side Oncam 3D dewarping
- microSD up to 512GB (FAT32, class 10), ONVIF Profile S/G/T; optional heater module (CA-GHM1-O) for cold start to -40C
